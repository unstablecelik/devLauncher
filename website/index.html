FAQ

Is devLauncher free?

Yes — GPLv3 free software. The source is open, and the launcher updates itself so you always run the newest build.

Which loaders are supported?

Vanilla, Fabric, Quilt, NeoForge and Forge. Instances remember their loader, so mixed setups simply work.

Do I need Java installed?

No. devLauncher auto-installs the right OpenJDK (Temurin, Java 8 → 27) per version and even per instance.

How does P2P multiplayer work?

It opens your LAN world to an invite link — directly to friends over the internet, no port forwarding, no accounts, no third-party servers. Remote Play (via Sunshine/Moonlight) is also built in.

Is it safe?

Downloads are checksum-verified, the launcher never executes shell commands, mods come from Modrinth, and every change lands in a reversible history. See docs/CODE-SIGNING.md for release signing status on each platform.

Windows says "unknown publisher" — why?

Windows binaries are signed when signing certificates are configured for a release; otherwise SmartScreen may warn. macOS builds can likewise be notarized — the infrastructure is in place and documented.
